During my internship at **Amazon Web Services Vietnam Company Limited** from **June 22, 2026 to August 15, 2026**, I had the opportunity to experience a professional working environment, learn about the process of deploying systems on a cloud computing platform, and apply the knowledge acquired at university to the team's project.

During the first few weeks, I focused on learning the fundamentals of AWS, using the **AWS Management Console**, and exploring common service categories such as Compute, Storage, Database, Networking, and Security. This process provided me with the necessary foundation before participating in the design and deployment of the project.

During the project implementation stage, I worked with the other team members to build **Live Auction**, an online auction platform that provides separate interfaces for users and administrators. The system was deployed using a serverless architecture on AWS, while Terraform was used to manage the infrastructure according to the Infrastructure as Code model.

Through the project, I studied and practiced with the following services and tools:

* AWS IAM and Amazon Cognito.
* Amazon S3 and Amazon CloudFront.
* AWS Lambda.
* Amazon API Gateway REST API.
* API Gateway WebSocket.
* Amazon DynamoDB.
* Amazon SQS FIFO.
* Terraform.
* Git and GitHub.
* Hugo and Markdown.

In addition to participating in the project, I prepared weekly worklogs, developed the Workshop content with Hugo, collected supporting screenshots from the AWS Management Console, and wrote the internship report in both Vietnamese and English.

I also participated in researching and sharing knowledge with the AWS Study Group community. The published articles covered deploying a React/Vite website on Amazon S3, managing connections between AWS Lambda and Amazon RDS, and optimizing storage costs with S3 Storage Classes and Lifecycle Policies.

The internship helped me improve my ability to study independently, search for technical documentation, use AWS services, work with Infrastructure as Code, manage source code, and prepare technical documentation. I also realized that I still have limitations in communication, problem-solving, and practical system deployment experience.

## Strengths

Through the internship, I identified the following strengths:

* I proactively researched documentation and experimented with new technologies.
* I was responsible for my assigned work and made every effort to complete it on schedule.
* I remained persistent when identifying causes and resolving deployment problems.
* I was willing to receive feedback and revise the report accordingly.
* I was able to organize technical knowledge into instructional documentation.
* I paid attention to security when using screenshots from the AWS Management Console.
* I proactively collaborated and shared tasks with other team members.
* I used Git and GitHub to manage, update, and integrate source code.
* I completed the report content in both Vietnamese and English.
* I contributed to the team's shared Workshop documentation.

## Areas for Improvement

In addition to the results achieved, I identified several areas that require further improvement:

* Develop deeper knowledge of AWS architecture, security, monitoring, and cost optimization.
* Improve communication, idea presentation, and work-progress reporting skills.
* Learn to ask clearer questions when encountering technical problems.
* Improve my ability to analyze the root cause of a problem before selecting a solution.
* Improve my ability to read technical documentation in English.
* Gain more experience in system testing and handling practical situations.
* Divide team responsibilities more clearly to avoid concentrating too much work near the end of the project.
* Prepare a more detailed schedule for product development, testing, and report writing.
* Learn more about CI/CD processes and system operation after deployment.
* Practice presenting important information concisely while maintaining sufficient detail.

## Development Plan After the Internship

After completing the internship, I plan to:

* Review and organize the knowledge gained from the AWS services used in the project.
* Gain more practical experience with Terraform and Infrastructure as Code.
* Study serverless and event-driven architectures in greater depth.
* Research system-monitoring approaches using Amazon CloudWatch.
* Improve my understanding of IAM, data security, and the principle of least privilege.
* Continue improving the Live Auction system when possible.
* Practice deploying additional projects on AWS.
* Continue sharing the knowledge I have gained with the community.

## Overall Evaluation

Overall, the internship helped me better understand the process of building and deploying a practical system on AWS. I had the opportunity to combine knowledge of programming, cloud computing, Infrastructure as Code, source code management, teamwork, and technical documentation.

Although the results were not completely perfect and I still have several areas to improve, I completed the primary tasks, participated in building the team's product, and completed the internship report according to the requirements.

I rate my overall internship performance as **Fair**. The internship has provided a foundation for me to continue improving my technical expertise, communication skills, problem-solving mindset, and professional working style.
